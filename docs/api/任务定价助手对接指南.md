# 任务定价助手前端对接指南

本文说明前端如何调用后端 AI 任务定价助手，完成“任务草稿 -> AI 报价 -> 用户反馈 -> 接受并创建任务”的完整流程。

## 1. 流程总览

```text
1. 前端收集任务草稿
2. POST /api/v1/ai/task-pricing-sessions/ 创建定价会话
3. 后端返回 quote_payload
4. 前端展示奖励/惩罚建议
5. 用户选择：
   - 接受：POST feedback action=accept
   - 偏高/偏低/详细说明：POST feedback action=revise
6. 如果 revise，后端返回新的 quote_payload，前端继续询问用户
7. 如果 accept，后端创建正式 Task，并在响应里返回 created_task
```

所有接口都需要 JWT：

```http
Authorization: Bearer <access_token>
```

## 2. 创建定价会话

```http
POST /api/v1/ai/task-pricing-sessions/
```

### 2.1 一次性任务示例

```json
{
  "task_payload": {
    "title": "完成数据库课程复习",
    "description": "整理索引、事务、范式相关笔记",
    "task_type": "one_time",
    "recurrence": "none",
    "settlement_track": "regular",
    "difficulty_level": "medium",
    "progress_target": 100,
    "tags": ["study", "database"]
  }
}
```

### 2.2 日常任务示例

```json
{
  "task_payload": {
    "title": "英语听力 30 分钟",
    "task_type": "daily",
    "recurrence": "daily",
    "settlement_track": "regular",
    "difficulty_level": "medium",
    "metric_key": "study_minutes",
    "target_value": 30,
    "progress_target": 100,
    "tags": ["english"]
  }
}
```

### 2.3 每周周期任务示例

```json
{
  "task_payload": {
    "title": "每周健身 3 次",
    "task_type": "recurring",
    "recurrence": "weekly",
    "settlement_track": "regular",
    "difficulty_level": "medium",
    "weekdays": [1, 3, 5],
    "progress_target": 100,
    "tags": ["fitness"]
  }
}
```

`weekdays` 取值：

```text
0 = 周一
1 = 周二
2 = 周三
3 = 周四
4 = 周五
5 = 周六
6 = 周日
```

### 2.4 每月周期任务示例

```json
{
  "task_payload": {
    "title": "每月读完一本书",
    "task_type": "recurring",
    "recurrence": "monthly",
    "settlement_track": "regular",
    "difficulty_level": "low",
    "month_days": [28],
    "progress_target": 100,
    "tags": ["reading"]
  }
}
```

### 2.5 探索任务示例

探索任务适合科研、调试、创作等难以精确量化进度的任务。

```json
{
  "task_payload": {
    "title": "排查训练脚本问题",
    "task_type": "one_time",
    "recurrence": "none",
    "settlement_track": "exploration",
    "difficulty_level": "high",
    "estimated_focus_minutes": 180,
    "progress_target": 100,
    "tags": ["coding", "research"]
  }
}
```

探索任务必须提供：

```json
{
  "estimated_focus_minutes": 180
}
```

## 3. 创建会话响应

响应外层仍是统一格式：

```json
{
  "success": true,
  "code": "OK",
  "message": "任务定价会话已创建",
  "data": {}
}
```

前端主要读取：

```json
{
  "id": 12,
  "status": "waiting_feedback",
  "task_payload": {},
  "quote_payload": {
    "reward_primary": 30,
    "penalty_primary": 10,
    "price_tier": "small",
    "confidence": 0.86,
    "reasoning": "定价理由",
    "risk_notes": [],
    "user_fit_notes": [],
    "llm_style_payload": {
      "task_type": "daily",
      "settlement_track": "regular",
      "feedback_rounds": 0
    }
  },
  "feedback_history": [],
  "created_task": null
}
```

建议前端展示：

- `quote_payload.reward_primary`：建议奖励
- `quote_payload.penalty_primary`：建议惩罚
- `quote_payload.reasoning`：定价说明
- `quote_payload.risk_notes`：风险或缺失信息
- `quote_payload.user_fit_notes`：结合用户画像的说明

## 4. 用户反馈或接受

```http
POST /api/v1/ai/task-pricing-sessions/{session_id}/feedback/
```

### 4.1 接受当前定价

```json
{
  "action": "accept"
}
```

接受后，后端会：

- 创建正式任务
- 写入 `reward_primary`
- 写入 `penalty_primary`
- 设置 `pricing_status=applied`
- 更新用户动态画像
- 在响应 `created_task` 中返回创建出的任务

前端可以读取：

```json
{
  "data": {
    "status": "accepted",
    "created_task": {
      "id": 31,
      "title": "英语听力 30 分钟",
      "reward_primary": 35,
      "penalty_primary": 10,
      "pricing_status": "applied"
    }
  }
}
```

### 4.2 认为定价偏高

```json
{
  "action": "revise",
  "feedback_direction": "too_high",
  "feedback_text": "这个任务比较轻，奖励和惩罚都可以低一点。"
}
```

### 4.3 认为定价偏低

```json
{
  "action": "revise",
  "feedback_direction": "too_low",
  "feedback_text": "这个任务需要查资料和总结，奖励可以高一点。"
}
```

### 4.4 详细反馈

```json
{
  "action": "revise",
  "feedback_direction": "detail",
  "feedback_text": "奖励可以保持，但惩罚偏重。我最近压力比较大，希望失败成本轻一些。"
}
```

`revise` 后，后端会返回新的 `quote_payload`。前端继续展示新报价，直到用户接受。

## 5. 字段枚举

### task_type

```text
daily       日常任务
recurring   周期任务
one_time    一次性任务
```

### recurrence

```text
none
daily
weekly
monthly
```

### settlement_track

```text
regular       常规轨道
exploration   探索轨道
```

### difficulty_level

```text
low
medium
high
```

### feedback_direction

```text
too_high  当前定价偏高
too_low   当前定价偏低
detail    详细说明
```

## 6. 前端推荐页面状态

```text
editing_task_draft
  -> pricing_loading
  -> waiting_user_feedback
  -> repricing_loading
  -> accepted
```

错误处理建议：

- `400`：任务草稿字段不合法，展示字段错误。
- `401`：登录过期，重新登录。
- `404`：会话不存在或不属于当前用户。
- `500`：模型或服务异常，提示稍后重试。

## 7. 注意事项

- `revise` 至少需要传 `feedback_direction` 或 `feedback_text`。
- `accept` 后会真正创建任务，不应重复提交。
- 已接受的会话不能继续调整。
- 探索任务必须提供 `estimated_focus_minutes`。
- `weekly` 必须提供 `weekdays`。
- `monthly` 必须提供 `month_days`。
